# 功能设计

## 数据表

| 表 | 用途 |
|:---|:---|
| `recharge_preset` | 充值面额 |
| `recharge_order` | 充值单：pending/paid/failed/cancelled；仅 balance 类型 |
| `billing_transaction` | 流水：`type` recharge\|consume\|refund；必填 `product`；`balance_after`；可选 `ref_id` |
| `user_monthly_consumption` | 按 `user_id`+`bill_month` 汇总 consume（对外 JSON 仍用 `year_month`） |

无 DB 外键；多表用显式 SQL JOIN/按 id 查询。

## 用户侧 API（Bearer）

- `GET /api/wallet/balance`
- `GET /api/wallet/presets`
- `GET /api/wallet/pay-channels`：已启用的支付渠道（`wechat` / `alipay`）
- `POST /api/wallet/recharge`：`amount` + 可选 `channel`（`wechat`|`alipay`，默认优先微信）→ 建 pending 单；微信就绪返回 `code_url`；支付宝 page 模式返回 `pay_url`（可作二维码内容）；支付宝 precreate 模式返回 `code_url`；`RECHARGE_DEV_AUTO=1` 且无可用渠道时允许 `POST /api/wallet/recharge/{id}/dev-pay`
- `GET /api/wallet/recharge/orders`：当前用户充值订单分页
- `GET /api/wallet/recharge/{order_id}`
- `GET /api/wallet/transactions?page=&page_size=&product=`
- `GET /api/wallet/bills`：月度消费列表
- `POST /api/wallet/notify/wechat`：验签解密后按 `out_trade_no` 入账（`payment_channel=wechat`）
- `POST /api/wallet/notify/alipay`：表单异步通知验签后按 `out_trade_no` 入账（`payment_channel=alipay`）；成功响应纯文本 `success`
- `POST /api/auth/password/reset`：手机号+验证码重置密码（无需登录）

## 充值状态机

```
pending --(微信成功/支付宝成功/dev-pay)--> paid（加余额 + recharge 流水 product=manager）
pending --(主动取消/超时标记)--> cancelled / failed
```

入账幂等：已 paid 直接返回当前余额。`payment_channel` 记 `wechat`|`alipay`|`dev`。

## S2S（`X-Manager-Key` = `MANAGER_S2S_KEY`）

- `GET /api/s2s/wallet/balance?phone=`
- `POST /api/s2s/wallet/deduct`：`phone|user_id`, `amount`, `product`, `ref_id`, `remark`；余额不足 400
- `POST /api/s2s/wallet/credit`：退费/补偿入账，`type=refund`

扣款同时更新 `user_monthly_consumption`。

## 微信支付

env：`WECHAT_PAY_*`；Native 扫码；`notify_url` 指向本服务公网地址。

## 支付宝支付

模块 `alipay_pay.py`，env：`ALIPAY_*`。

| 变量 | 说明 |
|:---|:---|
| `ALIPAY_ENABLED` | `1` 启用 |
| `ALIPAY_APP_ID` | 开放平台 APPID |
| `ALIPAY_GATEWAY` | 默认 `https://openapi.alipay.com/gateway.do` |
| `ALIPAY_APP_PRIVATE_KEY_PATH` | 应用私钥 PEM（或裸 base64，启动时补头） |
| `ALIPAY_PUBLIC_KEY_PATH` | 支付宝公钥 PEM（验签） |
| `ALIPAY_NOTIFY_URL` | 异步通知，如 `https://hipp.site/api/wallet/notify/alipay` |
| `ALIPAY_RETURN_URL` | 可选同步跳转 |
| `ALIPAY_TRADE_MODE` | `page`（电脑网站支付，默认）或 `precreate`（当面付预下单出 QR） |

VoiceFix / hipp-https **不**实现支付宝回调；仅代理或透传 manager 的 `channel` / `pay_url` / `code_url`。

## 控制台充值 UI（mgr / vf / cert）

自上而下：

1. **支付渠道大卡片**（两列）：微信 / 支付宝，点击选中（非 Radio 小控件）
2. **面额网格**（两列大按钮，高度约 48px，对齐 VoiceFix 尺寸）
3. **自定义金额输入 + 充值按钮**

# 约束与边界

- 不做会员档位、赠送分钟。
- 业务消费明细仍可由各产品自存；平台流水只记金额与产品标签。
- 支付宝加签仅公钥模式 RSA2；不做证书模式资金支出。
