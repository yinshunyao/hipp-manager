# 功能设计

## 平台管理员

- 表 `ops_admin`：`admin_id`（UUID）、`username`（唯一，可用手机号）、`password_hash`、`created_at`、`updated_at`。
- 初始密码常量 `123456`：CLI `create` / `reset-password` 均只收 `--username`，口令固定为该常量；不提供命令行自定义密码。
- 登录后自改密：`POST /api/ops/auth/password`（body `old_password`+`new_password`，须 ops Bearer）。
- CLI：`python -m manager.ops_admin create|reset-password --username <name>`。
- 登录 `POST /api/ops/auth/login` → 签发 ops Bearer（载荷含 `ops=1`，写入 Redis 白名单，键前缀 `mgr:ops:`）。
- 校验 `POST /api/ops/auth/verify`：body `username`+`password`，或 Header Bearer ops 令牌；供他产品管理端校验。成功返回 `{ok:true, username}`。
- 普通用户会话不可访问 `/api/ops/*`（除 login/verify）。

## 运营台 UI

- 路径：`/mgr/manager/`（与账户台 `/mgr/` 分离；同站约定各产品管理端为 `/{product}/manager/`）；未登录跳转 `/mgr/manager/login`。
- 页面：用户列表、流水、充值订单、手工动账（入账/扣款）、改密。
- 用户：筛选 `register_source`、手机号；拉黑 `is_blocked`；运营重置**普通用户**密码。
- 流水/充值：筛选 `product`、`biz_type`、手机号/user_id。
- 手工动账：调用内部 credit/debit，必填 `product`、`biz_type`、金额、备注；备注自动追加 `ops:<username>`。
- 改密：当前管理员填写旧密码与新密码，调用 `/api/ops/auth/password`。

## 运营 API（Bearer ops）

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| POST | `/api/ops/auth/password` | 管理员自改密；`old_password`+`new_password` |
| GET | `/api/ops/users` | 分页；query: phone, register_source, is_blocked |
| PUT | `/api/ops/users/{user_id}/blocked` | body `{blocked:bool}` |
| POST | `/api/ops/users/{user_id}/password` | body `{password}`（重置普通用户） |
| GET | `/api/ops/transactions` | 分页；product, biz_type, phone |
| GET | `/api/ops/recharge/orders` | 分页；product, status, phone |
| POST | `/api/ops/wallet/credit` | 入账 type=refund 或调增；product+biz_type |
| POST | `/api/ops/wallet/debit` | 扣款 type=consume；product+biz_type |

## 共享管理员接入（or / vf）

- or 管理端密码登录：先 `POST` manager `/api/ops/auth/verify`；成功则发本产品 staff JWT（可无本地影子账号或标记 platform_ops）；失败再走本地 `vadmin_auth_user`。
- vf Django Admin：认证后端增加 manager ops 校验；成功建立 Django staff session。
- cert：本轮若已有管理登录则同样接入 verify；无则仅文档预留。

# 数据模型

| 表/字段 | 说明 |
|:---|:---|
| `ops_admin` | 见上 |
| `user.register_source` | 产品码；建号时写入 |
| `user.is_blocked` | 拉黑；登录拦截 |
| `billing_transaction.biz_type` | 必填 |
| `recharge_order.product` / `biz_type` | 按下单入口写入 |

# 约束与边界

- 不做角色菜单 RBAC。
- 不迁 or 智能体/角色、vf 任务申诉 UI。
- 产品码白名单与全局规则一致：`mgr|or|vf|cert`。
