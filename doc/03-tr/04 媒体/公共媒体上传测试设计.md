# 测试范围

- `POST /api/media/upload`：鉴权、product、大小、落盘与返回 URL。
- `GET /media/{path}`：上传后可读。
- or 门面：`POST /mp/chat/upload` 经 manager 落盘（联调/手工）。

# 测试用例

| 编号 | 前置条件 | 步骤 | 预期结果 | 自动化 |
|:---|:---|:---|:---|:---|
| TM01 | 已登录 Bearer | 上传小 PNG，`product=or` | 200，`url` 含 `/media/or/`，落盘存在 | 手工/后续 pytest |
| TM02 | 无 Bearer | 上传 | 401 | 手工 |
| TM03 | 已登录 | `product=bad` | 400 | 手工 |
| TM04 | 已登录 | 超过 `MEDIA_MAX_BYTES` | 400，不落盘 | 手工 |
| TM05 | TM01 成功 | GET 返回的 `url` 路径 | 200，内容与上传一致 | 手工 |
| TM06 | or 已登录且 manager 在线 | `/mp/chat/upload` 合法图 | 200，`url` 指向 manager `/media/` | 手工联调 |
| TM07 | or 无 manager_token | `/mp/chat/upload` | 明确错误（须重新登录同步账户） | 手工 |
| TM08 | 已上传本人文件 | `DELETE /api/media` 带 url | 200，文件不可再 GET | 手工 |
| TM09 | 他人 path | `DELETE /api/media` | 403，文件仍在 | 手工 |
| TM10 | S2S + 正确 product | `POST /api/s2s/media/delete` | deleted≥1 | 手工 |

| TM12 | 话题结束且方案未含附件 URL | 结束后 | 该会话 attachments 中未出现在助手正文的媒体被删 | 手工联调 |
| TM13 | S2S gc，keep 不含旧孤儿，mtime&gt;24h | 调 `/api/s2s/media/gc` | deleted≥1 | 手工 |
