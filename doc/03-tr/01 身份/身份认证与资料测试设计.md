# 测试用例

| 编号 | 前置 | 步骤 | 预期 | 自动化 |
|:---|:---|:---|:---|:---|
| A1 | SMS_MOCK=1 | 发码 → 用 123456 登录新手机号 | 200，返回 token，用户已建 | 手工/后续 API |
| A1b | 已登录 | `POST /api/auth/logout` 后再 `GET /api/auth/me` | 401 | 手工 |
| A1c | 同站已登录 or 与 cert | 在 or 退出后再打开/刷新 cert | cert 须落登录页 | 手工 |
| A1c2 | 同站仅在 cert 登录 | 打开/刷新 `/mgr/` | mgr 已登录，无需再登 | 手工 |
| A1c3 | 同站仅在 mgr 登录 | 打开/刷新 `/cert/` | cert 已登录（经 SSO 换票），无需再登 | 手工 |
| A1c4 | 同站仅在 or 登录 | 打开/刷新 `/mgr/` | mgr 已登录 | 手工 |
| A1c5 | 同站仅在 mgr 登录 | 打开 `/or/`、`/or/manager/`、`/vf/` | 均已登录（管理端须该手机号有权限） | 手工 |
| A1c6 | 同站已登录 cert/or/vf | 在 `/mgr/` 退出后再调各产品需鉴权业务接口 | 均 401（不必等产品本地令牌过期） | 手工 |
| A1c7 | manager 进程不可达 | 调 cert/or/vf 需鉴权接口 | 均 401；or `mp_guest` 不受影响 | 手工 |
| A1d | SMS_MOCK=0 且已装 SDK | 真发短信 | 手机收到码并可登录 | 手工 |
| A2 | 已设密码 | 密码登录正确/错误 | 正确 200；错误 400 | 手工 |
| A3 | 已登录 | PATCH 昵称 | me 返回新昵称 | 手工 |
| A4 | 无密码用户 | POST password 无旧密码 | has_password=true | 手工 |
| A5 | 有密码 | 旧密码错误改密 | 400 | 手工 |
| A6 | 过期 token | GET me | 401 | 手工 |
| A7 | 生产 MySQL `hipp_manager` | 启动后表已建；`import_legacy` 后 | or/VoiceFix 手机号可在 manager 查到；余额≥VoiceFix | 手工 |
| A8 | 同号两端都有口令 | 导入后用原 or 或 VoiceFix 口令登录 | 至少一侧口令可用（规则：优先 VoiceFix） | 手工 |
