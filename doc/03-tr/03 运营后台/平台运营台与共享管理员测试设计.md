# 测试范围

CLI 建管理员（初始 `123456`）、CLI 重置回初始密码、登录后自改密、ops 登录、用户拉黑/改密、流水筛选、手工动账、他产品 verify、普通用户不可进 ops。

# 测试用例

| 编号 | 前置 | 步骤 | 预期 | 自动化 |
|:---|:---|:---|:---|:---|
| O1 | 空库 | CLI `create --username admin`（无密码参数） | 用 `123456` login 得 token | 手工 |
| O2 | 已自改密 | CLI `reset-password --username admin` 后 login | `123456` 可登，旧自设密码不可 | 手工 |
| O2b | ops 已登录 | `/manager/password` 填旧/新密码 | 新密码可登，旧密码不可 | 手工 |
| O3 | 普通用户 Bearer | GET /api/ops/users | 401 | 手工 |
| O4 | ops Bearer | 拉黑用户后该用户密码/短信登录 | 400/禁止 | 手工 |
| O5 | ops | 流水筛 product=vf | 仅 vf 行 | 手工 |
| O6 | ops | credit 缺 biz_type | 400 | 手工 |
| O7 | ops | credit product=vf biz_type=refund_manual | 余额增，流水含 product+biz_type | 手工 |
| O8 | 正确用户名密码 | POST /api/ops/auth/verify | ok=true | 手工 |
| O9 | or 管理端 | 用平台管理员密码登录 | 进入管理端（本地员工不存在亦可） | 手工 |
| O10 | vf Admin | 同上 | 进入 Admin | 手工 |
| O11 | 打开 /mgr/manager/ | 未登录 | 管理端登录页，非账户台 `/mgr/` 登录 | 手工 |
