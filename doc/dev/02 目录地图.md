# 目录地图

## 工程根

```text
hipp-manager/
├── .env / .env.sample     # 配置（从 sample 复制）
├── requirements.txt
├── data/
│   ├── manager.db         # SQLite（DATABASE_URL 为空时）
│   └── media/             # 公共媒体落盘
├── server/
│   ├── manager/           # 主应用包
│   │   ├── __main__.py    # python -m manager
│   │   ├── app.py         # FastAPI 组装、挂载 /mgr /media
│   │   ├── api.py         # 身份 / 钱包 / 运营 / S2S 路由
│   │   ├── auth_service.py
│   │   ├── wallet_service.py
│   │   ├── session.py
│   │   ├── sms.py
│   │   ├── db.py          # 引擎 + schema
│   │   ├── products.py    # 产品码 / biz_type
│   │   ├── ops_admin.py   # 运营管理员 CLI
│   │   ├── import_legacy.py
│   │   ├── wechat_pay.py / alipay_pay.py
│   │   └── config.py
│   └── media/             # POST /api/media/* 、S2S、静态目录配合
└── web/
    ├── vite.config.ts     # base=/mgr/，dev 代理 /api → :9100
    └── src/
        ├── App.tsx        # 用户端 + 运营台路由
        ├── api/           # auth / wallet / ops / sso / client
        ├── pages/         # 用户页；ops/ 运营页
        ├── layouts/
        └── store/
```
