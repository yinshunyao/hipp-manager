# 开发约定

1. **改需求先改 OR**：`doc/01-or/` → 同步 `02-dr` + `03-tr` → 再改代码（workspace `rules-workflow`）。
2. **库表**：在 `db.py` 用 SQLAlchemy 建表；业务查询/更新写原生 SQL，勿用 ORM 查询 API。
3. **产品码**：仅 `mgr` / `or` / `vf` / `cert`；禁止别名 `manager` / `voice` 新写入（见 `server/manager/products.py`）。
4. **资金字段**：充值单、流水、S2S 扣款/入账必须带 `product` + `biz_type`。
5. **错误码**：业务失败返回稳定 `code` + `message`；前端按 `code` 分支（见 workspace `rules-api-error-codes`）。
6. **中文界面**：枚举展示用中文映射，勿直接露英文码。
7. **充值二维码**：用户端必须用 Modal，禁止嵌在充值页正文流。
8. **稀疏表单**：资料/登录/充值区用窄列（如 `.page-content-narrow`），勿撑满主栏。
