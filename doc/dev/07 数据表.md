# 数据表（逻辑）

启动时 `init_schema` 自动建表（SQLite / MySQL 方言在 `server/manager/db.py`）。主要表：

| 表 | 用途 |
|:---|:---|
| `user` | 用户、余额、`register_source`、拉黑 |
| `ops_admin` | 平台运营管理员 |
| `recharge_preset` | 充值面额 |
| `recharge_order` | 充值单（`product` / `biz_type` / 渠道） |
| `billing_transaction` | 流水 |
| `user_monthly_consumption` | 月消费汇总 |
| 媒体相关 | 见 `../02-dr/04 媒体/` |

无数据库层外键；多表关联在 SQL 里显式 `JOIN`。
