# 前端路由

`basename` = Vite `base`（生产/开发均为 `/mgr/`）。

| 路径（相对 basename） | 页面 |
|:---|:---|
| `/login` | 用户登录 |
| `/profile` | 资料 |
| `/wallet` | 钱包 / 充值 |
| `/transactions` | 流水 |
| `/bills` | 月账单 |
| `/manager/login` | 运营登录 |
| `/manager/users` | 用户管理 |
| `/manager/transactions` | 运营流水 |
| `/manager/recharge` | 充值单 |
| `/manager/adjust` | 手工入账/扣款 |
| `/manager/password` | 运营改密 |

浏览器完整 URL 示例：`http://127.0.0.1:5175/mgr/wallet`、`…/mgr/manager/users`。

路由定义真源：`web/src/App.tsx`。
