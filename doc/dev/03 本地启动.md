# 本地启动

## 后端

```bash
cd hipp-manager
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp -n .env.sample .env
# 开发建议保持：SMS_MOCK=1、RECHARGE_DEV_AUTO=1、DATABASE_URL 空（SQLite）
PYTHONPATH=server python -m manager
```

- 监听：`MANAGER_HOST` / `MANAGER_PORT`（默认 `0.0.0.0:9100`）
- 探活：`curl http://127.0.0.1:9100/health` → `{"ok":true}`
- 若已 `npm run build`：浏览器打开 `http://127.0.0.1:9100/mgr/`

## 前端（热更新）

```bash
cd hipp-manager/web
npm install
npm run dev
```

- 地址：`http://127.0.0.1:5175/mgr/`（`VITE_BASE` 默认 `/mgr/`）
- Vite 把 `/api` 代理到 `http://127.0.0.1:9100`；开发时**先起后端**

## 生产构建前端

```bash
cd hipp-manager/web
npm run build   # 产出 web/dist，由后端挂载 /mgr/
```

## 常用环境变量（开发）

完整表见工程根 `.env.sample` 与 [`../99-ops/run.md`](../99-ops/run.md)。本地最少关心：

| 变量 | 开发建议 |
|:---|:---|
| `MANAGER_SESSION_SECRET` | 任意本地密钥 |
| `MANAGER_S2S_KEY` | 与业务侧 `HIPP_MANAGER_KEY` 一致 |
| `DATABASE_URL` | 空 → SQLite `data/manager.db` |
| `SMS_MOCK` | `1` |
| `RECHARGE_DEV_AUTO` | `1`（无真实支付时模拟入账） |
| `MEDIA_PUBLIC_BASE` | 如 `http://127.0.0.1:9100` |
