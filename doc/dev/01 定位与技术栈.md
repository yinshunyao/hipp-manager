# 定位与技术栈

## 定位

- **做什么**：跨产品统一身份（手机号）+ 共享钱包（充值/流水/账单）+ 平台运营台 + 公共媒体。
- **产品码**：`mgr`（用户端 `/mgr/`，运营台 `/mgr/manager/`）。
- **谁调用**：hipp-or、VoiceFix（vf）、hipp-https（cert）等通过用户 Bearer 会话或 S2S（`X-Manager-Key`）接入。
- **不做**：各产品业务审批 UI（留在各产品 `/…/manager/`）；微信小程序登录（or 侧本地）；第二套资金账本。

## 技术栈

| 层 | 选型 |
|:---|:---|
| 后端 | Python 3.12、FastAPI、Uvicorn、SQLAlchemy（建表）+ **原生 SQL**（业务读写）、bcrypt、Redis（会话/短信，mock 可内存） |
| 支付 | 微信 Native、支付宝 RSA2（`page` / `precreate`）；开发可用 `RECHARGE_DEV_AUTO` |
| 短信 | 阿里云；`SMS_MOCK=1` 固定码 `123456` |
| 前端 | React 19、Vite 8、Ant Design 6、Zustand、React Router 7 |
| 库 | 开发默认可 SQLite（`data/manager.db`）；**生产须 MySQL**（`DATABASE_URL`） |
