# `hipp-manager/doc/dev/` 目录说明

## 目录用途

开发手册：本地联调、目录结构、接口/路由索引、接入约定。给开发者快速上手，不替代 `01-or` / `02-dr` / `99-ops`。

## 文档范围

- 允许：启动步骤、目录地图、API/路由索引、开发约定、联调清单、业务接入摘要。
- 禁止：完整需求原文、详细表字段设计（放 `02-dr`）、生产部署长文（放 `99-ops/run.md`）、密钥与未公开主机路径。

## 编辑规则

- 入口索引为 `readme.md`；专题拆成独立文档，命名 `编号 主题.md`。
- 变更后同步检查工程根 `readme.md` 中指向本目录的链接。
- 接口或启动方式变更时，核对 `../02-dr/`、`../99-ops/run.md` 是否需同步。

## 协作约定

- 需求真源：`../01-or/`；设计真源：`../02-dr/`；运行真源：`../99-ops/`。
- 本目录只做开发侧导航与摘要，细节以对应 OR/DR/Ops 为准。
