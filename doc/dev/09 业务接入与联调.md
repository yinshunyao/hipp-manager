# 业务接入与联调

## 业务系统接入（开发侧）

| 系统 | 典型配置 |
|:---|:---|
| 通用 | `HIPP_MANAGER_BASE=http://127.0.0.1:9100` |
| 需 S2S 扣款（如 VoiceFix） | 另配 `HIPP_MANAGER_KEY` = 本服务 `MANAGER_S2S_KEY` |
| 支付回调 | 微信/支付宝 `notify_url` 必须指向 **本服务**公网路径（见 [`../99-ops/run.md`](../99-ops/run.md)） |

同站登录态：多产品共享会话令牌；业务接口应以本服务 `GET /api/auth/me`（或等价校验）判定在线，勿只信本产品本地令牌。

## 联调检查清单

- [ ] 后端 `/health` 正常；`.env` 已从 sample 复制
- [ ] `SMS_MOCK=1` 下可用验证码 `123456` 登录 `/mgr/login`
- [ ] 前端 dev 与后端同时开；充值在 `RECHARGE_DEV_AUTO=1` 下可走 `dev-pay`
- [ ] 运营台：先 CLI 建管理员，再登录 `/mgr/manager/`
- [ ] 改接口后同步对应 `02-dr` / `03-tr`；运维相关改 `99-ops`
- [ ] 不把真实密钥、客户路径写进文档或提交进库
